## 주요 프로젝트

### 1️⃣ **웹 밸런스게임**
- **설명**: 특정 상황에 대한 두 가지 선택지 중 하나를 고르는 **웹 기반 밸런스 시뮬레이터**  
- **기간**: (예: 2024.08 ~ )
- **기술 스택**: **Spring Boot**, **React**, MySQL, Git, Github Actions, Docker
- **주요 기능**
  - 질문 생성 & 선택지 등록
    - 사용자가 직접 주제를 작성하고 2개 이상 선택지를 만들어 실시간 투표를 열 수 있음
  - 실시간 투표 및 집계
    - 참여자들이 각 선택지를 선택하면 모든 사용자 화면에 즉시 투표 비율 업데이트
  - 결과 시각화
    - 선택지별 투표 현황을 그래프·퍼센트로 시각화
- **성과 / 특징**
  - 프론트–백 간 REST API 설계 및 배포 자동화
- **링크**: [이터널리턴 밸런스게임 깃허브](https://github.com/Eternal-Return-User-Creator/ER_balance_game)

---

### 2️⃣ **도서관 웹사이트 프로젝트**
- **설명**: 42 SEOUL 커뮤니티를 위한 도서관, 집현전의 **웹 프로젝트**  
- **기간**: (예: 2022.06 ~ 2025.04)
- **기술 스택**: **TypeScript** Express, **AWS EC2**, **CodeDeploy**, Nginx, MySQL, Git, Github Actions, Docker  
- **주요 기능**
  - 도서 등록·검색·대여 관리
  - S3 기반 이미지 업로드, CI/CD 파이프라인
- **성과 / 특징**
  - 42 SEOUL 커뮤니티 이용자에게 제공하는 도서관 웹사이트 개발
  - AWS EC2 서버 마이그레이션, 모니터링, CodeDeploy 등의 유지보수
  - 리뷰, 태그 및 도서와 관련된 Rest API 설계 및 구현으로 사용자 만족도 개선
  - TypeORM 을 사용한 리팩토링 주도, 교육, 강연
  - 자동 배포 파이프라인 구축으로 운영 효율 극대화
- **링크**: [집현전 깃허브](https://github.com/jiphyeonjeon-42/backend)

### 3️⃣ **보드게임 점수판**
- **설명**: 커스텀 TRPG ‘용사 이야기’ 전용 **커스텀 점수판**  
- **기간**: 2025.06 ~ 진행 중
- **기술 스택**: **C# .NET 8 (WinForms)**, JSON
- **주요 기능**
  - CorpsMember·Monster·Artifact 등 복잡한 JSON 데이터 관리
  - 더블버퍼링 기반 커스텀 UI(스코어보드, 스크롤 뷰포트)
  - ClickOnce 배포 및 GitHub Pages 연동
- **성과 / 특징**
  - WinForms의 성능 최적화 및 대규모 커스텀 컨트롤 구현
- **링크**: [용사 이야기 깃허브](https://github.com/nyj001012/The-legacy-of-the-braveries-score-board)

### 4️⃣ **DICOM 변환 프로그램**

- **기간**: (예: 2020.11 ~ 2021.01)
- **기술 스택**: **C# .NET 4 (WinForms)**, **fo-dicom**
- **주요 기능**
